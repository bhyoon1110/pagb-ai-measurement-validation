# Aggregate verified results

This directory contains aggregate, non-image-identifying outputs from the provenance-verified run.

- `evaluation/`: primary metrics, specimen-cluster confidence intervals, failure counts, measurement-protocol audit, coupling summary, and figures.
- `sweep/`: descriptive threshold sensitivity on the fixed cached predictions.
- `corruption/`: aggregate controlled-intervention results and figures.
- `paper/`: machine-readable values exported for the manuscript.

Large intervention-level tables, example arrays, field-level matches, and input hashes are omitted from the public repository. The authoritative denominators are 82 total fields, 69 specimens, and 78 fields with both prediction and reference G defined.
